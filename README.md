预测价格方向时，你是“涨就买、跌就空仓”。现在改为**根据波动率方向调整仓位**：

```python
def backtest_vol_direction(prob, returns, target_vol=0.15):
    """
    波动率方向策略：
    - 预测波动率上升 → 减仓至50%（避险）
    - 预测波动率下降 → 满仓100%（进攻）
    """
    prob = pd.Series(prob, index=returns.index)
    
    # 关键修正：t日信号 → t+1日收益（无前视偏差）
    shifted_returns = returns.shift(-1).dropna()
    shifted_prob = prob.loc[shifted_returns.index]
    
    # 仓位：vol上升 → 0.5，vol下降 → 1.0
    positions = np.where(shifted_prob > 0.5, 0.5, 1.0)
    
    strategy_returns = positions * shifted_returns
    # 然后用你原来的业绩计算函数（夏普、回撤等）
```
